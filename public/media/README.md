# Body loop media

ใส่วิดีโอร่างกายสำหรับหน้า Idle ที่โฟลเดอร์นี้ โดยใช้ชื่อใดชื่อหนึ่ง:

- `body-loop.webm` (แนะนำ หากต้องการ alpha/transparency)
- `body-loop.mp4`

แนวทางไฟล์:
- full body อยู่กึ่งกลางเฟรม
- กล้องนิ่ง
- background ดำ หรือ alpha
- loop 8–15 วินาที
- ไม่มีข้อความ/โลโก้ในตัววิดีโอ
- แนะนำ 1080p หรือ 4K ตาม resolution ของ projector master

หน้าเว็บจะ fallback เป็น vector body อัตโนมัติถ้าไม่พบไฟล์วิดีโอ
